# Support

## Avant de signaler un problème

1. Consultez le [Dépannage](../troubleshooting/index.md) : la plupart des situations y
   sont couvertes.
2. Consultez la [FAQ](../faq/index.md).
3. Vérifiez les [Limites connues](../reference/limitations.md) : certains comportements
   sont volontaires (absence de synchronisation, refus de conclure sous les seuils…).
4. **Sauvegardez vos données** avant toute manipulation :
   Menu `⋯` → *Sauvegarder mes données (JSON)*.

## Comment signaler un problème

Digestor est un projet open source hébergé sur GitHub : les problèmes se signalent dans
le **suivi d'incidents** du dépôt
<https://github.com/nouhailler/digestor>.

Aucun autre canal de support n'est publié à ce jour. `À vérifier` — si un canal de contact
direct doit être ajouté, il devra figurer ici.

## Informations à fournir

Un signalement utile contient :

| Information | Exemple |
|---|---|
| **Version de l'application** | 0.15.2 |
| **Appareil** | iPhone 13 / Pixel 7 / PC portable |
| **Système et version** | iOS 18.2 / Android 15 / Windows 11 |
| **Navigateur et version** | Safari 18 / Chrome 131 |
| **Application installée ?** | Écran d'accueil, ou onglet du navigateur |
| **Message d'erreur exact** | Copié tel quel, avec son code éventuel |
| **État du réseau** | En ligne / hors ligne / réseau restreint |
| **Étapes de reproduction** | 1. … 2. … 3. … |
| **Comportement attendu** | Ce que vous pensiez obtenir |

## ⚠️ Ne joignez jamais de données personnelles

Votre fichier de sauvegarde contient **l'intégralité de votre journal de santé**. Ne le
joignez jamais à un signalement public.

Si un extrait est indispensable pour reproduire un problème (par exemple un JSON
d'import refusé), **anonymisez-le** : remplacez les aliments, les notes et le nom du
patient par des valeurs fictives, et ne conservez que la structure.

Ne transmettez jamais votre **clé API OpenRouter**.

## Demander de l'aide sur l'usage

Pour une question d'usage plutôt qu'un défaut :

- L'aide `?` de chaque écran donne les astuces contextuelles.
- Le [Guide utilisateur](../guide/index.md) décrit chaque écran.
- Les [Fonctionnalités](../features/index.md) décrivent chaque fonction en détail.

## Questions médicales

**Digestor ne peut pas répondre à une question médicale**, et le support non plus.
Adressez-vous à un médecin ou à un gastro-entérologue. Voir
[Informations légales](../legal/index.md).
