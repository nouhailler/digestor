# Recherche dans le journal

## Description

Retrouver les jours où apparaît un aliment, un symptôme ou un mot de vos notes.

## Objectif

Répondre à « quand ai-je mangé ça pour la dernière fois ? » sans faire défiler les dates.

## Prérequis

Aucun.

## Comment l'utiliser

1. **Menu `⋯` → Rechercher dans le journal**.
2. Tapez au moins **2 lettres** dans le champ
   *« Aliment, symptôme ou note (2 lettres min.)… »*.
3. Touchez un résultat : le Journal s'ouvre sur ce jour.

## Options

La recherche porte simultanément sur les **aliments**, les **symptômes** et les
**notes**.

## Paramètres associés

Aucun.

## Données utilisées

Tous les jours enregistrés, en lecture locale.

## Résultat

Une liste de jours correspondants, avec le contexte de la correspondance.

## Fonctionnement hors connexion

Intégral.

## Fonctionnement en ligne

Identique.

## Limites

- Recherche textuelle simple : pas de synonymes, pas de recherche approximative.
- Pas de filtre par plage de dates.

## Erreurs possibles

Aucune.

## Dépannage

Aucune procédure spécifique.
