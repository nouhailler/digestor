# Digestor — Documentation

**Journal alimentaire et suivi des symptômes** (candidose intestinale, SIBO, SII).
Application web progressive (PWA) **100 % hors-ligne**, sans compte et sans serveur :
toutes vos données restent sur votre appareil.

## En une phrase

Vous notez ce que vous mangez et ce que vous ressentez ; Digestor colore, compte,
trace des courbes et — seulement quand les données sont suffisantes — signale des
associations entre un aliment et un symptôme. Une couche d'IA **optionnelle**
(OpenRouter) peut analyser un aliment, une journée ou une période.
